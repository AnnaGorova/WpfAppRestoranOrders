## Налаштування бази даних вручну:

### Варіант 1: Запуск всього скрипту
1. Відкрийте `SqlScripts/CreateTables.sql` в SQL-sever
2. Переконайтеся, що база `RestoranOrderDb` існує
3. Натисніть F5 (запустить весь скрипт)

### Варіант 2: Поетапний запуск
1. Виділіть  кожен блок окремо, по одному!!!

### Перевірка:
В кінці скрипту є SELECT-и для перевірки даних.


# Після успішного налаштування:
Запустіть програму - автоматично відкриються 4 вікна:

- Адмін-панель + чат 

- Клієнтське вікно 

- Вікно кухні + чат

- Головне вікно (закрийте для виходу!!!!)
